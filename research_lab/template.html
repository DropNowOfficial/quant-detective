这些数值如何解读？

CAGR = (期末净值 / 初始资金) ^ (365.2425 / 实际日历天数) − 1。波动率使用日收益标准差 × √252；Sharpe 假设无风险利率为 0。胜率与盈亏比仅统计已完成交易，缺失值保持为 —。事件平均收益不能替代组合年化。

价格距离实验
合成示例 · 非市场数据
拖动输入，观察 ATR 如何改变相同价格差的含义。
合成示例的计算结果
标准化距离 D5 = (C − MA5) / ATR5
此处只验证 −0.10 ≤ D5 ≤ 0.20 和 |缺口 / ATR5| ≤ 0.50。斜率、流动性、波动率上限、相对强弱排序与资金约束未在此验证，不能据此称为可交易信号。日量比也不是同分钟 RVOL。
01 / 时间边界
前日锚点和当日完成值
前日 MA5(t) = [C(t−1) + … + C(t−5)] / 5
当日 MA5(t) = [C(t) + … + C(t−4)] / 5
主规则的 MA5 与 ATR5 都截止前一交易日。变体把窗口推进到信号日收盘，因此今天的价格也会移动锚点。两者是不同的冻结实验；都最早在下一日开盘执行。
02 / 波动单位
TR 不只是最高减最低
TR(t) = max[H−L, |H−C(t−1)|, |L−C(t−1)|]
TR 保留跨日跳空。这里 ATR5 是 5 个 TR 的算术平均。Wilder 平滑则递推 ATR(t) = [4 × ATR(t−1) + TR(t)] / 5；相同周期名不代表相同数列。
03 / 相对强弱
收益率差的单位是百分点
RS20 = R(股票, 20日) − R(QQQ, 20日)
15% − 10% = 5 个百分点
这是排序用的收益差，不是“相对收益增长 5%”，也不是风险调整后的 alpha。主规则先筛资格，再按 RS20、前日美元成交额、代码排序。
事件均值不能直接年化
信号可能重叠，空闲资金、仓位上限、成本和持有时间都不同。把单笔平均收益反复复利，会隐含一个不存在的连续满仓账户。只有可执行资金约束下的净值路径，才有组合 CAGR。
看过的历史不再是盲测
逐日揭示能训练决策纪律，但不能抹去已经看过的结果。停留在当前观察池还会遗漏退市、被剔除或没有进入关注列表的股票，形成幸存者与选择偏差。
完整披露试参，不挑赢家
4 种规则 × 4 个持有期 × 4 档成本构成每数据集 64 个可见场景。多个好结果仍可能来自反复试验；总历史试验次数未知时，不能编造 PBO 或 Deflated Sharpe。
