# 交付前反证与遗漏审查

## 本轮已经改变设计的发现

- 旧1196个事件同时可能占用最多20仓。已新增有限现金账本，而非将事件均值年化。
- 五年缓存的2022熊市原先未进入三年研究。已纳入2022，并追加2017起长历史；长窗收益明显低于近期窗口，QQQ长窗价格收益更高。
- 旧来源88根OHLC相互矛盾，第二来源均有有效对应bar。仍保留两源独立实验，未按有利结果混接。
- SNDK、SPCX、VRT和WDC存在跨源差异；META更名导致旧源2022前半年的109session缺口。已经记录为数据身份/调整风险，没有都写成IPO。
- 已增加“不能凭未来坏收盘取消当日有效开盘买入”测试，以及缺价后暂停新仓、保留延迟退出与未平仓的契约。
- 同一MA5名称可能指前日锚点或当日完成值。已分开实验，ATR也明确为简单TR平均。
- 显示的参数情形不是最优解；完整192格、逐股剔除、年份/子期、费用与资金容量都可检查。
- 公开Git无原始行情，精确重放必须另持授权快照。已提供指纹清单与不匹配拒绝机制。
- 独立代码审查复现了两个工程问题：单交易日的日历构建失败；无序集合使等权基准浮点末位及实验ID跨进程漂移。已修复，并以完整研究依赖和三个不同Python哈希种子验证。
- 旧工作台的子进程曾依赖原工作目录，已修正核心验证的调用位置；快照包补齐请求清单，保留源字段语义。公开审计文件的重命名映射和文件指纹也已记录。
- 本地预览服务增加Host限制，防止非本机Host读取私有研究目录。

## 我最担心仍会错的地方

第一是数据的经济含义：OHLC几何正确与两个网站接近，并不能认证分拆、退市和当时股票池。第二是把一个价格收益实验当成真实持股财富曲线。第三是看到高年化后继续试参，直到偶然结果看起来稳定。这些问题未通过，所以系统仍将validated_metrics置空，不能开启自动交易。

## 保留的边界

本轮没有补造盘中VWAP/RVOL，没有冒称历史真正盲测，没有给缺失估值序列贴“基本面价值”标签，没有用机构名称为绩效背书。验证过程的具体结果在research_outputs/verification.json；独立数据审查与代码审查分别保存，不相互代替。

## 多市场扩展的交付前修复

真实端到端查询又发现了现货目录超过响应上限的问题；按官方参数省略 permissionSets 后完整活动目录恢复。另通过回归修复极小价格被舍入为零、股票/加密资产跨市场错标、OKX 永续被标为交割、矛盾 OHLC 被接受，以及本地 curl 默认配置可能改变无认证单次 GET 的问题。取消连接后不再发后续页，已通过独立本地 HTTP 检查。

美股目录不覆盖全部 OTC，A 股披露目录不认证当前上市状态；部分股票交易场所、北交所分钟数据、半日市日历仍未认证。HTTP 429、451 与 200 拦截 HTML 已实测保留，不能用“已实现适配器”冒充所有市场均可用。新入口不计算交易信号，既有冻结研究没有移植成分钟策略。
