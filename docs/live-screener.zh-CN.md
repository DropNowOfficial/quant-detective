# Quant Detective LIVE 使用说明

默认首页是持续扫描终端。启动后直接看当前关注池、每项条件、排名和来源时效；原研究放在 RESEARCH，原手动行情终端在「原始K线」。

## 启动

仓库分支 `feature/live-screener-20261004`。需要 uv、Python 3.11+ 与 curl。找不到 uv 或 curl 命令时，请先安装相应工具并重新打开终端。

```bash
uv sync --frozen
uv run --frozen qd-market serve
```

打开 `http://127.0.0.1:8767/`。`uv sync --frozen` 把依赖安装到项目的 `.venv`；`uv run --frozen` 会选择该环境，无需先激活。Windows 在同步成功后可双击仓库中的 `start-live.cmd`；它明确运行 `.venv\Scripts\python.exe`，不会调用 PATH 中其他 Python。环境或依赖缺失时，在仓库目录重新执行 `uv sync --frozen`。需保持这个进程运行；一个离线HTML或一次对话响应无法常驻抓取行情。浏览器页面每2秒读取服务状态，后台目标每12秒开始一个批次；慢请求、多页面、来源退避会延长实际批次间隔，界面报告实际耗时。

## 日常用法

1. 选 Binance 现货 / Gate USDT 永续 / OKX 永续等来源和1m、5m或15m。
2. 默认关注池从当次真实目录匹配主要品种。打开「管理关注池」，读取完整目录，搜索并加入所需代码（最多12个）。可选「全目录分批扫描」；加密扫描只比较USDT计价。
3. READY=分钟规则全部匹配，WATCH=趋势通过但仍缺确认，未匹配=趋势/波动/流动性条件未过。点击整行看具体公式和未通过值。无READY是有效结果，不会降低门槛伪造候选。
4. 数据问题包括BLOCKED、STALE、ERROR。抓取超过36秒，或最新闭合K线落后超过一个周期加15秒，都不能保留当前READY。公开行情请求耗时并不等于交易所行情延迟。
5. CSV / JSON导出当前观察，包括来源、UTC时间、规则版本与界面状态。REPLAY显示本服务进程最近30个已捕获批次，明确为历史；重启不保留会话回放。

## 指标口径

| 指标 | 明确计算方式 |
|---|---|
| 最近价 | 当前返回的最后一根close；带星号表示尚未收盘 |
| 信号收盘价 | 最新可用、已收盘K线close |
| MA5 / MA20 | 当前分钟周期5根/20根简单均线 |
| 双斜率 | 当前MA5-上一MA5，以及(当前MA5-前二MA5)/2，都大于0 |
| ATR14 | 最近14根 max(H-L,abs(H-前收),abs(L-前收)) 的算术均值；不是Wilder递推 |
| 距MA5 | (信号收盘价-MA5)/ATR14；默认绝对值≤0.5 |
| VWAP60 | 最近60根成交额/基础币量；Gate使用目录的线性合约乘数。缺必要字段时显示HLC3按volume加权近似，不称精确VWAP |
| RVOL20 | 最新完整K线量 / 前20根完整K线均量，不含本根；默认≥1.2。不是20日同分钟RVOL |
| RS20 | 本品种20根收益减基准同期收益，单位百分点；时间严格一致。加密BTC、美股QQQ、A股510300，均与被比较品种同来源；510300通过单独的ETF资产身份路径验证，不放入A股股票目录 |
| 流动性 | 最近60根来源报价币成交额；门槛默认0（关闭），可调。缺失时正门槛会阻断，不以0冒充 |
| 匹配度 | 通过条件数/实际检查条件数；不是胜率或收益预测 |

READY还要求：close>MA20，连续2根close都在各自VWAP60之上，RS20≥0，ATR14/close≤12%。指标只接受至少61根连续的已收盘有效K线。没有偷偷移植或宣称验证完整HARNESS V2；原日线研究和工作台仍在原目录。

## 来源和覆盖

- Binance现货：`https://data-api.binance.vision/api/v3/klines`，主动买量只读取下标9。
- Gate USDT永续：`https://api.gateio.ws/api/v4/futures/usdt/candlesticks`，volume是合约张数、sum是报价币成交额；没有主动买量。
- OKX：`https://www.okx.com/api/v5/market/candles`，vol、volCcy、volCcyQuote与confirm分开读取；来源拦截不会替换为Gate或Binance价格。
- 美股/A股保留真实目录与Yahoo分钟查询；休市、限流、时段断层、未认证报价身份都可能阻断，不能宣称美股/A股订阅级实时。Gate的股票类合约不是美股现金证券。
- OKX交割与币本位暂无同合约类型的标准基准，RS缺失阻断READY，仍可查看原始K线。全目录含多少品种、已扫多少和已过时多少均明确展示。
- 同时最多4个页面订阅、全服务最多一个扫描批次、4个并发GET；每批最多12个品种，加必要的同源基准。全目录轮转不会伪称整个市场12秒全覆盖。

未连接账户、不使用密钥、不自动交易。上述限制不阻止持续分析；它们用于明确当前数据和计算结果能回答什么。

## 复核

`make verify` 是规范验证入口。`node tests/browser_live.cjs` 是开发环境的浏览器测试（需Playwright/Chromium）。真实来源验证保留请求时刻、HTTP状态和覆盖元数据，不把原始行情提交Git。

研究摘要随完整源码提供；独立wheel安装若未带研究摘要会明确返回不可用，LIVE运行不依赖该文件。
