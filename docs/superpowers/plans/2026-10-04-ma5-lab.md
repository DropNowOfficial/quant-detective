# MA5 research lab implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver reproducible portfolio diagnostics, verified source evidence, and an interactive teaching laboratory.
**Architecture:** A pure deterministic research module ingests external local snapshots, computes chronological decisions, simulates cash-bounded portfolios and renders an evidence-backed standalone page. It remains separate from the default research graph.
**Tech Stack:** Python standard library, existing pytest, local HTML/CSS/JavaScript; current screener remains independently runnable.
**Spec:** docs/superpowers/specs/2026-10-04-ma5-lab-design.md

## Global Constraints
- No raw market datasets in Git; caches stay outside the repo.
- Source + known_at; missing is not zero; no trading actions.
- Primary 5 positions, 3 sessions, 10bps round trip, USD10,000; sensitivities disclosed rather than selected for returns.
- Current-vintage reconstruction; not untouched out-of-sample or proof of alpha.
- make verify is the canonical verification entrypoint.

## Review Focus
- Invalid entry day's close must not be used to decide that morning's entry.
- Missing marks, delayed exits and corporate actions cannot silently produce valid performance.
- Calendar-year and partial-period return denominators must include initial capital and entry cost.
- Scenario controls, source links and exports must reflect the same selected scenario.
- Exact replay needs private authorized raw snapshots; public CI tests are synthetic only.
